Bonus Tolerance (MMC)

For a hole, MMC is the smallest allowed size and bonus grows as the actual size increases. For a shaft/pin, MMC is the largest allowed size and bonus grows as the actual size decreases. Departure in the wrong direction is clamped to 0 — it's a size violation, not a bonus.
