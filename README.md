# Machinist Calc

An offline desktop calculator suite for machinists — thread calculations, tap
drills, speeds & feeds, surface finish, bolt circles, true position, and ISO
tolerances — inspired by [theoreticalmachinist.com](https://theoreticalmachinist.com).
Built with Electron; runs on **Windows, macOS, and Linux**. No network access,
no telemetry — everything runs locally in the app.

## Calculators

| Calculator | Standard referenced |
| --- | --- |
| Unit Converter | Exact length/speed unit definitions |
| Tap Drills (Imperial & Metric) | ASME B1.1 / ISO 68-1, ISO 965-1 |
| Thread Calculator (Unified & Metric) | ASME B1.1 / ISO 68-1 |
| Speeds & Feeds | Conventional machining relations |
| Bolt Circle | Analytic geometry |
| True Position | ASME Y14.5 |
| Surface Finish | Theoretical Ra approximation (Machinery's Handbook) |
| ISO Tolerance / Limits | ISO 286-1 |
| Reference Charts | ASME B94.11M drill size tables |

Each panel in the app states which standard (if any) its formula is based
on, and every formula in [`src/js/calc-core.js`](src/js/calc-core.js) is
documented with the same citation in its JSDoc comment. Where a calculator
uses a simplification (e.g. the ISO 286-1 tolerance calculator uses the
nominal size directly rather than the official size-range midpoint), that's
called out explicitly rather than silently approximated.

## Development

Requires [Node.js](https://nodejs.org) 18+.

```bash
npm install
npm start        # launch the app
npm test          # run the calculation-engine test suite
npm run lint       # lint
```

## Building installers

```bash
npm run dist:win     # Windows (NSIS installer)
npm run dist:mac      # macOS (DMG) — must run on macOS
npm run dist:linux     # Linux (AppImage + .deb)
```

Cross-compiling macOS builds only works on a macOS host/CI runner; the
GitHub Actions workflow in `.github/workflows/ci.yml` builds and validates
packaging on all three OSes on every push and pull request.

## Project structure

```
main.js              Electron main process (window, menu, icon)
preload.js            No-op — the renderer is fully self-contained
src/index.html         App shell (sidebar nav + calculator panels)
src/css/style.css       Dark theme
src/js/calc-core.js      Pure calculation engine (used by the renderer AND tests/run.js)
src/js/app.js           DOM wiring for the calculator panels
tests/run.js           Dependency-free test suite for calc-core.js
scripts/generate_icons.py  One-off script that generated build/icon.{png,ico,icns}
build/                Packaged-app icons
```

## Icons

`build/icon.png` / `.ico` / `.icns` are a placeholder "MC" monogram
generated by `scripts/generate_icons.py` (Python + Pillow). Swap in real
branding by replacing those three files — no code changes needed.
